# PRD — KTR 위클리 트렌드: 푸드 관심사 조회

> 버전: v0.1 (초안)  
> 작성일: 2026-05-11  
> 상태: 사용자 승인 대기

---

## §1 개요

### 배경 및 목적

사용자가 K-Trend Radar(KTR)의 위클리 데이터를 통해 **현재 SNS에서 급상승하거나 주목받는 K-푸드 관심사 정보를 주 단위로 확인**할 수 있는 기능을 신규 개발한다.

이 기능은 식품 업계 종사자(연구원, 마케터, 기획자)가 SNS 트렌드를 빠르게 파악하고 비즈니스 의사결정에 활용할 수 있도록 지원한다.

### 핵심 가치

- 매주 갱신되는 SNS 트렌드 데이터를 한눈에 파악
- 급상승 관심사와 일반 SNS 관심사를 구분하여 우선순위 파악 가능
- 개별 게시물 원문 확인 및 한국어 번역 제공으로 심층 분석 지원
- 관심 게시물 저장으로 반복 탐색 효율화

## §4 기능 요구사항

### FR-1: 위클리 트렌드 목록 화면

**FR-1.1 탭 네비게이션**
- 메인탭: "위클리 트렌드"(활성) | "데이터 라이브러리"
- 서브탭: "푸드 관심사"(활성) | "신상텀"
- 활성 탭: Bold 16px, 하단 2px border (#2c3244)
- 비활성 탭: Medium 16px, 색상 #7e8896

**FR-1.2 필터 바**
- 기간 필터: 주(Week) 단위 선택, 선택된 주 범위 표시 (예: "2026년 4월 3주 - 2026년 4월 3주")
- GSP 카테고리 필터: 드롭다운 단일 선택 (기본값: 전체)
- 필터 변경 시 즉시 서버에 API 재요청 (클라이언트 필터링 없음)

**FR-1.3 정렬**
- 정렬 옵션: "최신 날짜순" | "반응량 높은순"
- 기본 정렬: 최신 날짜순
- 선택된 항목: Bold, 미선택: Regular
- 정렬 변경 시 서버 API 재요청

**FR-1.4 "데이터 수집 안내" 툴팁**
- 우상단 "데이터 수집 안내 ?" 클릭 시 툴팁 표시
- 툴팁 내용: 데이터 수집 방식/출처 안내 (백엔드 제공 텍스트)

---

### FR-2: 급상승 관심사 섹션

**FR-2.1 섹션 타이틀**
- 🔥 아이콘 + "급상승 관심사" (headline2Bold 24px)
- 서브텍스트: "SNS 언급량 기준 빠르게 성장 중인 K-푸드 관심사" (body2Regular 14px #7e8896)
- 우측 정보: "트렌드 키워드 TOP 1 / {키워드명}" + [🏆 키워드 랭킹] 버튼
  - 키워드 랭킹 버튼: 별도 키워드 랭킹 화면으로 이동 (라우팅 대상은 별도 확인 필요)

**FR-2.2 카드 그리드**
- 7열 그리드, 고정 너비 (카드 width ≈178px, gap 포함 1391px 내 배치)
- 최대 14개 카드 (2행 × 7열) 표시
- 페이지네이션 없음 (이 섹션은 고정 개수)

**FR-2.3 카드 구성 (급상승)**

| 영역 | 내용 |
|------|------|
| 썸네일 | 세로형 이미지 (aspect ratio 268:476), border-radius 8px |
| 채널 배지 | 좌상단, 채널 로고(TikTok 등) 원형 24px |
| 급상승 배지 | 좌상단, ⚡ + "급상승" 파란색 pill (#1e6eff) |
| 북마크 | 우상단 아이콘 버튼 |
| GSP 배지 | 우하단, 카테고리명 dark pill |
| 반응 바 | ♥ 좋아요수 💬 댓글수 (12px #7e8896) |
| 스파크라인 | 주별 반응량 추이 미니 차트 (h=48px, bg=#f6f7f8) |
| 텍스트 | 게시물 영문 설명 (2줄 말줄임), 날짜, 한국어 키워드(파란색 3줄) |

---

### FR-3: SNS 관심사 섹션

**FR-3.1 섹션 타이틀**
- "SNS 관심사" (headline2Bold 24px) + 총 개수 (Regular 14px #7e8896)

**FR-3.2 카드 그리드 + 무한 스크롤**
- 7열 그리드
- 최초 로딩: N개 (백엔드와 협의 필요, 권장 14~21개)
- 스크롤 하단 도달 시 추가 로딩 (Intersection Observer)
- 로딩 중 스켈레톤 UI 표시

**FR-3.3 카드 구성 (SNS 관심사)**
- 급상승 관심사 카드와 동일하되 아래 항목 제외:
  - 스파크라인 차트 없음
  - 급상승 배지 없음 (채널 로고만 표시)

---

### FR-4: 카드 상세 모달

**FR-4.1 모달 진입/종료**
- 진입: 카드 클릭
- 종료: 우상단 X 버튼 클릭 또는 모달 바깥 영역 클릭
- 라우팅 변경 없음 (URL 변경 없음)

**FR-4.2 모달 레이아웃**
- 배경 어두워짐 (backdrop)
- 좌우 분할: 좌측 이미지 전체, 우측 게시물 정보

**FR-4.3 모달 우측 콘텐츠**

| 영역 | 내용 |
|------|------|
| 유저 정보 | 프로필 아바타 + username + 더보기(...) 버튼 |
| 게시물 원문 | 영문 캡션 + 해시태그 (스크롤 가능) |
| 번역 | "번역 보기 (한국어)" 링크 클릭 시 한국어 번역 토글 표시 (서버 사전 번역 데이터) |
| 반응 정보 | ♥ 좋아요수, 💬 댓글수, 날짜 |
| 트렌드 상태 | "Emerging" 등 상태 레이블 |
| 배지 영역 | 채널 로고 + 급상승 배지 + 관심사 키워드 pills |
| 트렌드 차트 | 주별 SNS 반응량 라인 차트 (x축: 주차, y축: 반응량) |
| 하단 CTA | [🔖 저장] 버튼, [↗ 게시물 이동] 버튼 |

**FR-4.4 게시물 이동**
- 외부 SNS 원본 URL을 새 탭으로 오픈 (`target="_blank"`)

**FR-4.5 번역 토글**
- 기본 상태: 영문 원문 표시
- "번역 보기 (한국어)" 클릭 → 한국어 번역 텍스트로 교체
- 이미 번역 데이터가 API 응답에 포함 (추가 API 호출 없음)

---

### FR-5: 북마크 저장/해제

**FR-5.1 저장**
- 카드 우상단 북마크 아이콘 클릭 → 서버에 저장 API 호출
- 저장 성공: 아이콘 filled 상태로 변경
- 저장 실패: 에러 토스트 표시

**FR-5.2 해제**
- 저장된 상태에서 북마크 클릭 → 해제 API 호출
- 해제 성공: 아이콘 outline 상태로 변경

**FR-5.3 인증**
- 비로그인 시 북마크 클릭 → 로그인 유도 (구체적 동작은 기존 인증 플로우 따름)

---

### FR-6: 데이터 다운로드

**FR-6.1 진입**
- SubHeading 우측 "↓ 데이터 다운로드" 버튼 클릭

**FR-6.2 다운로드 범위**
- 현재 적용된 필터 기준 (기간, GSP 카테고리)의 전체 데이터
- 파일 형식: CSV 또는 Excel (백엔드와 협의 필요 — 미결)

**FR-6.3 상태 처리**
- 다운로드 시작 시 로딩 표시
- 완료 시 파일 자동 다운로드
- 실패 시 에러 토스트 표시

## §8 데이터 모델 (추정)

> API 명세는 백엔드 문서 참조. 아래는 프론트엔드에서 필요한 데이터 구조 추정.

### 카드 (Post)

```typescript
interface Post {
  id: string;
  channel: 'tiktok' | 'instagram' | string; // SNS 채널
  channelLogoUrl: string;
  thumbnailUrl: string;
  captionOriginal: string;       // 영문 원문
  captionTranslated?: string;    // 한국어 번역 (사전 번역)
  hashtags: string[];
  gspCategory: string;           // GSP 카테고리
  gspCategoryLabel: string;
  keywordTags: string[];         // 관심사 키워드 pills
  isRising: boolean;             // 급상승 여부
  trendStatus?: 'Emerging' | string;
  authorUsername: string;
  authorAvatarUrl: string;
  likeCount: number;
  commentCount: number;
  publishedAt: string;           // ISO 날짜
  externalUrl: string;           // 원본 게시물 URL
  koreanTitle: string;           // 한국어 키워드 (파란색 표시)
  sparklineData?: number[];      // 급상승 섹션용 스파크라인 데이터
  isBookmarked: boolean;
}
```

### 트렌드 차트 데이터 (모달)

```typescript
interface TrendChartData {
  postId: string;
  series: {
    week: string;   // 예: "Jan W3, 2026"
    value: number;  // 반응량 (좋아요 + 댓글)
  }[];
}
```

### 필터/정렬 파라미터

```typescript
interface FilterParams {
  weekRange: {
    startWeek: string;  // 예: "2026-W14"
    endWeek: string;
  };
  gspCategory?: string;  // 미선택 시 전체
  sortBy: 'latest' | 'reaction';
  page?: number;
  pageSize?: number;
}
```
